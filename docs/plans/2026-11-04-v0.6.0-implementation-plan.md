# v0.6.0 Usage Panel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show Claude, Grok Bot and Codex usage in one panel with each service's logo, a UseReserve-style menu bar item ("N% remain"), and a new app icon.

**Architecture:** One shared model (`ServiceID`, `ServiceLimit`, `ServiceState`) that every service maps into. Claude keeps its existing sign-in and polling and is mapped at the edge. Grok Bot and Codex are `ServiceReader`s polled by a `ServicesPoller`. The menu bar and the panel are pure functions of `[ServiceID: ServiceState]`.

**Tech Stack:** Swift 5.9, AppKit, XCTest, xcodegen. No new dependencies.

**Spec:** `docs/plans/2026-11-04-v0.6.0-usage-panel-design.md`

## Global Constraints

- Follow every rule in `CLAUDE.md`:
  - Edit `project.yml`, then `xcodegen generate`. Never hand-edit `.xcodeproj`. If `project.pbxproj` conflicts on a merge, regenerate it.
  - Never `exportArchive`.
  - `setupStatusItem()` runs before any WebKit object.
  - Tests touch only `io.rsla.ClaudeUsageWidget.tests*` Keychain services.
- Tokens: never log, store or refresh another app's token. That covers Claude Code's and Codex's.
- Grok Bot: open only the account-slot blob and the weekly-usage blob. Never `sand-secrets.json`, never the "Grok Bot Safe Storage" Keychain item.
- Tests never read real files under `~/Library` or `~/.codex`. They use a temp directory.
- Menu bar: no motion, and the width never changes with the numbers. The title is the system's own menu bar text. Only the badge dot is amber (`#F59E0B`) or red (`#EF4444`).
- Copy is everyday words. No em or en dashes in any UI string. "N% remain" in the menu bar, "N%" in panel rows.
- Thresholds stay as they are: `RingColorState.from(percent:)` gives normal under 60% used, amber from 60 to 84%, red from 85%.
- Run the full suite: `xcodebuild test -scheme ClaudeUsageWidget -destination platform=macOS CODE_SIGNING_ALLOWED=NO`. It must be green at every commit.
- Commit messages end with the repo's attribution lines.

## Review Focus

- **A Grok Bot reading days old** (Rahul uses Grok Bot mostly on his phone). The panel shows its age, and the menu bar never shows it as current. Test in Task B2 (`testStaleReadingIsDimmedAndFreshOneWins`) and Task B4 (`testStaleGrokBotSectionSaysItsAge`).
- **The pinned service is hidden or signed out.** The menu bar falls back to "lowest" instead of a dead item. Test in Task B2 (`testPinnedServiceHiddenFallsBackToLowest`).
- **Grok Bot installed but signed out, or a different account slot.** It shows a hint and never crashes. Test in Task A1 (`testMissingUsageBlobSaysOpenGrokBot`, `testUnknownKindSaysOpenGrokBot`).
- **Codex `auth.json` present but its token expired.** A 401 gives a hint, with no refresh and no prompt. Test in Task A2 (`testUnauthorizedSaysOpenCodex`).
- **Hiding the last shown service.** It isn't allowed, because an empty panel is a dead end. Test in Task B4 (`testLastShownServiceCannotBeHidden`).

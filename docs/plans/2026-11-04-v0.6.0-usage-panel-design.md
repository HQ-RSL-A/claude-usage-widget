# v0.6.0: every AI's usage in one panel, UseReserve-style menu bar, new app icon

Rahul, 2026-11-04. Linear: HQ-189. Builds on v0.5.1 (HQ-188: no redraw loop, no password prompt).

## Why

Rahul uses UseReserve beside the widget and likes three things about it, in his words: "it always stays logged in", "I can click on it and view all the other LLMs' usages with their icons", "it's easy to read". He asked for the widget's menu bar to look like UseReserve's, for the panel to have "a decent ui/ux with the right llm logo", and for a better app icon ("You have freedom for the logo").

## What he decided

- Services: Claude, Grok Bot, Codex. Not Antigravity ("except Antigravity").
- Menu bar similar to UseReserve: a logo and "90% remain".
- Opted out of further questions ("Okay go ahead with the rest").

## My calls (told to him before building, not yet seen by him)

- **Menu bar:** the service's logo plus "N% remain". The number is the limit closest to running out across the shown services, with that service's logo. The "..." menu can pin one service instead. The width never changes with the numbers, the text is the menu bar's own text, and only a small badge dot on the logo turns amber or red. This keeps his 2026-10-26 rule that colored digits get lost on colored wallpapers.
- **Panel:** UseReserve's layout. "Usage Remaining" header with a "..." menu. One section per service: the icon of the app installed on his Mac, then rows of label, percent left and reset ("5hr Session  83%  2:10 PM", "Weekly  67%  Nov 10"). Claude's sign-in states and buttons live inside the Claude section. The "..." menu holds Refresh, Menu Bar Shows, Show (hide a service), Open at Login, Sign Out of Claude, Quit.
- **Grok Bot:** read from the usage file Grok Bot itself saves. No token, no Keychain, no prompt. It's only as fresh as the Grok Bot Mac app's last refresh, so the section says how old the reading is.
- **Codex:** read from Codex's own sign-in file and ChatGPT's usage endpoint. Shown only when Codex is signed in on the Mac. Rahul cancelled OpenAI on 2026-10-30 and Codex isn't installed, so it can't be checked live yet.
- **App icon:** a "reserve tank" orb, a glass circle with blue liquid about two thirds full, on an ink squircle. RSL/A blue (`#3b82f6` to `#0059C2`), drawn on the macOS icon grid.

## Goals

- One click shows every set-up service's remaining usage, with each service's real logo.
- Never asks for the Mac password (Claude via `/usr/bin/security` since v0.5.1; Grok Bot and Codex read files).
- The menu bar reads at a glance and never moves.

## Non-goals

- Antigravity.
- Grok Bot's live endpoint. It needs Grok Bot's encrypted token, which means a Keychain prompt after every update of this ad-hoc signed app.
- Refreshing any other app's token (Claude Code's or Codex's).
- Notifications (HQ-118), removing the embedded login (HQ-143).

## Anti-goals (a failure even if it works)

- Any password or Keychain prompt.
- A stale number shown as current.
- Motion in the menu bar, or a width that changes with the numbers.
- Battery use back above idle.

## Facts the builder needs (verified 2026-11-04)

**Grok Bot.** Files are in `~/Library/Application Support/Grok Bot/sand-client-persistence/`. Each file is named with the RFC 4648 base32 of its key, lowercase, no padding, plus `.blob`.
- The account slot is key `sand.client.slice.client-meta.account-slot` (file `onqw4zbomnwgszlooqxhg3djmnss4y3mnfsw45bnnvsxiyjomfrwg33vnz2c243mn52a.blob`). It holds `{"schemaVersion":1,"value":"<slot>"}`.
- Usage is key `sand.client.slice.account.<slot>.weekly-usage.cache`. It holds:
  ```
  {"schemaVersion":2,"value":{"kind":"present","selectedTeamId":null,
   "reading":{"usage":{"percentUsed":7.04,"nextResetMs":1794345715756,
   "isSandTrial":false,"hasNonZeroIncludedLimit":true,"isTeamSeat":false,
   "onDemand":null,"grokPlanLabel":"Grok Bot Plan","unifiedPlanName":"Premium"},
   "readAtMs":1793824425618},"expiresAtMs":1793910825946}}
  ```
- `percentUsed` is 0 to 100. Grok Bot rewrites the file when its UI refreshes, not on a timer, and its own time to live is 24 h.
- Never open `sand-secrets.json` or the "Grok Bot Safe Storage" Keychain item.

**Codex.** Read from CodexBar, which is MIT (`steipete/CodexBar`, `docs/codex.md`); not run live here.
- The auth file is `$CODEX_HOME/auth.json`, or `~/.codex/auth.json`, with `tokens.access_token` and `tokens.account_id`.
- Request: `GET https://chatgpt.com/backend-api/wham/usage` with `Authorization: Bearer <access_token>` and `ChatGPT-Account-Id: <account_id>`.
- Response: `rate_limit.primary_window` and `secondary_window`, each with `used_percent` (0 to 100), `limit_window_seconds` and `reset_at` (epoch seconds).
- Never refresh the token. Codex owns `auth.json`.

**Logos.**
- Panel: the app icon from `NSWorkspace`, by bundle id (`com.anthropic.claudefordesktop`, `com.anysphere.sand`, `com.openai.codex`).
- Menu bar marks: `claude.svg` and `codex.svg` from Lobe Icons (`lobehub/lobe-icons`, MIT, `packages/static-svg/icons/`). Grok Bot's mark is drawn by hand from its app icon: a round white blob with two slanted oval eyes.
